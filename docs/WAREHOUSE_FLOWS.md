# SmartPick V3 - Central Warehouse Flows

1. **Inbound**: Truck $\rightarrow$ Dock $\rightarrow$ Receiving $\rightarrow$ QC $\rightarrow$ Putaway $\rightarrow$ Storage
2. **Storage**: Inventory $\rightarrow$ Slotting $\rightarrow$ ABC Analysis $\rightarrow$ Replenishment $\rightarrow$ Cycle Count
3. **Order Fulfilment**: Sales Order $\rightarrow$ Planner $\rightarrow$ Wave $\rightarrow$ Queue $\rightarrow$ Pick $\rightarrow$ Pack $\rightarrow$ Ship
4. **Returns**: Customer $\rightarrow$ Inspection $\rightarrow$ Decision $\rightarrow$ Repair/Restock/Scrap
